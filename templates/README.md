# Templates (generated)

Generated by `scripts/sync-templates.ts` (`make sync-templates`). Do not
edit. Templates live in
[Seylo-dev/Templates](https://github.com/Seylo-dev/Templates): the format,
how to add one and the checks a pull request runs are in its README and
CONTRIBUTING.md.

This folder is the copy of the signed template catalog that ships with the
panel:

- `catalog.json`: every template (meta.yaml, index.ts and its logo), in the
  catalog format of `apps/panel/src/modules/templates/catalog-file.ts`.
- `catalog.json.minisig`: its signature by the release key, which also
  signs the catalog (`brand/brand.json` `templatesMinisignPublicKey`, the
  same value as `minisignPublicKey`). Until the Templates repository
  publishes its first catalog there is none: the copy here is the unsigned
  snapshot taken before that (sequence 0), and `make sync-templates` keeps
  it.
- `NOTICE` and `LICENSE.*`: the logos' credits, written from the catalog.

A panel uses this copy until it downloads a newer signed catalog from the
Templates repository's `catalog` release (every 6 hours, and on "Check for
new templates" on the Templates page), and always when it has no internet
access or the owner turned downloads off. `apps/panel/test/vendored-catalog.test.ts`
checks that every template here installs on this version of the panel.

Before tagging a release, run `make sync-templates` and commit the result;
`scripts/release-preflight.sh` refuses a release whose copy is older than
the published catalog.
